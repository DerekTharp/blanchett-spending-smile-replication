# Replication Package: The Retirement Spending Smile Revisited

Code and output tables for

> Tharp, D. (2026). The Retirement Spending Smile Revisited: Cross-Sectional Patterns versus
> Within-Household Dynamics. *Financial Planning Review*. https://doi.org/10.1002/cfp2.70051

The package reproduces every table and figure in the article from the raw RAND HRS/CAMS data
with a single command. Table and figure numbers below follow the published article; Tables
S1-S9 and Figure S1 are in the article's Supporting Information.

## Data availability

The analysis uses two restricted-access RAND datasets from the Health and Retirement Study.
Under the HRS Conditions of Use these microdata cannot be redistributed, so they are not
included here. Both are available free (with registration) from https://hrsdata.isr.umich.edu/:

- RAND HRS Longitudinal File 2022 (V1): `randhrs1992_2022v1.dta`
- RAND CAMS Data File 2021 (V1): `randcams_2001_2021v1.dta`

Place them as described in `data/raw/README.md`. The household-interval panel
(`data/processed/`) is regenerated by the pipeline and is likewise omitted. The aggregated
result tables in `peer_review/tables/` are included so that every reported number can be
checked without the microdata.

## Software

Python 3.12 or later. Install dependencies:

    pip install -r requirements.txt

Exact pinned versions from the reference run are in `requirements-lock.txt`.

## Reproducing all results

From the repository root, after placing the raw data:

    python peer_review/code/run_all.py

This runs the nine-stage pipeline (`01`-`09`) through the master driver, rebuilding every CSV
table in `peer_review/tables/` and every figure in `peer_review/figures/`. Bootstrap
operations are seeded (`random_seed=42`) for exact reproducibility.

To verify the shipped outputs (no microdata required):

    python peer_review/code/validate_outputs.py

`tests/test_artifact_outputs.py` checks that the result CSVs match the values reported in the
article; `tests/test_estimator_invariance.py` re-estimates the most ill-conditioned model and
confirms it is invariant to age centering (it skips automatically when the panel data are
absent).
