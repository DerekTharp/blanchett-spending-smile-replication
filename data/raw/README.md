# Raw data (not included)

The RAND HRS and RAND CAMS microdata cannot be redistributed under the HRS Conditions of Use.
Obtain them free (with registration) from https://hrsdata.isr.umich.edu/ and place them here:

    data/raw/randhrs1992_2022v1_STATA/randhrs1992_2022v1.dta
    data/raw/randcams_2001_2021v1/randcams_2001_2021v1.dta

Then run `python peer_review/code/run_all.py` from the repository root.
